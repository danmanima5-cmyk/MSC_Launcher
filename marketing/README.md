# MSC Launcher Metro advertising animation

Open `msc-launcher-ad.html` in a browser. The animation is a 22-second 16:9 Metro/Windows-8.1-inspired spot for the full MSC Launcher.

Recommended recording flow:

1. Open the HTML file.
2. Press `Fullscreen`.
3. Press `Replay`.
4. Record the browser window for 22 seconds with OBS or another screen recorder.
5. Add your licensed music track in the video editor and align the first beat with `Replay`.

The spot is now Metro UI only: launcher tiles unfold, Mods and Skins tiles are swapped by drag-and-drop, the tiles transition into real-style tabs for Mods, Skins, and Settings, one color circle changes the background pattern, and the camera zooms into the release tile. No commercial music file is bundled in the project.
