# Modern UI — картинки кнопок

Положи сюда PNG-файлы с именами строго из таблицы ниже (например `btn_launch.png`).
Картинка **полностью заменит вид кнопки**: текст, фон, рамка и заливка
скрываются, а PNG растягивается на всю область кнопки (на весь её
размер, без полей). Если файла нет — кнопка остаётся как была (с текстом).

Изображение можно класть любого размера (квадрат не обязателен — под
форму конкретной кнопки), формат PNG, с прозрачностью если нужно.
Чем выше разрешение картинки, тем чётче она будет смотреться на больших
кнопках (рекомендуется не меньше реального размера кнопки в пикселях,
для крупных кнопок типа "Играть" — от 300×80 px и выше).

Для кнопок «Играть» и «Аккаунт» на главной странице можно положить
отдельную картинку для английского языка: добавьте файл с суффиксом
`_eng` (`btn_play_eng.png`, `btn_account_eng.png`). Когда в настройках
выбран язык English, лаунчер автоматически берёт `_eng`-картинку вместо
обычной; для всех остальных языков используется обычный файл без
суффикса (`btn_play.png`, `btn_account.png`).

## Кнопки без своей картинки (намеренно)

Часть кнопок создаётся **динамически в циклах** (одна и та же функция
штампует много одинаковых кнопок с разным текстом/числом): кнопки
страниц пагинации модов (1, 2, 3…), вкладки (табы) внутри окон, плашки
выбора опций (например варианты загрузчика/версии), универсальные
кнопки-стрелки выпадающих списков и слайдеров. Прикрутить уникальную
картинку к каждой такой кнопке не имеет смысла (картинка одна, а кнопок
с разным текстом — много), поэтому они остаются с обычным отрисованным
стилем. Если нужно — могу сделать заменяемой какую-то конкретную группу
отдельно, просто скажи какую.
