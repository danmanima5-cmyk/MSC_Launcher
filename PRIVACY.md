# Политика конфиденциальности MSC Launcher

Последнее обновление: 04.07.2026

MSC Launcher может получать доступ к общедоступным данным Discord в пределах
выданных пользователем прав, включая идентификатор и никнейм пользователя,
сведения о серверах, на которые добавлено приложение, и текстовые команды.
Эти данные используются только для функций лаунчера, Discord Rich Presence и
внутренней статистики. Они не продаются, не передаются и не распространяются
третьим лицам.

Данные хранятся только пока это необходимо для работы приложения. Пользователь
может удалить приложение со своего сервера или отозвать авторизацию в
настройках аккаунта Discord, после чего обработка прекращается.
