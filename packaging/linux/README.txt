MSC Launcher for Linux

This archive contains an obfuscated release JAR; source files are not included.

Requirements: Java 8 or newer. For the embedded Microsoft OAuth window,
install your distribution's OpenJFX package as well.

Run: ./bin/msc-launcher

To make the launcher appear in an application menu for the current user:
  mkdir -p ~/.local/share/applications ~/.local/share/icons/hicolor/32x32/apps
  cp share/applications/io.github.danmanima5_cmyk.MSC_Launcher.desktop ~/.local/share/applications/
  cp share/icons/hicolor/32x32/apps/io.github.danmanima5_cmyk.MSC_Launcher.png ~/.local/share/icons/hicolor/32x32/apps/
