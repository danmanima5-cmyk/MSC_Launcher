# MSC Launcher Tiles for Windows 8.1

Настоящая APPX/Windows Store-style оболочка по модели Steam Tile. Она показывает
плитки разделов лаунчера, умеет создавать secondary tiles на начальном экране и
передаёт запуск установленному desktop companion через URI `msc-launcher://`.

Перед использованием APPX установите `MSC Launcher Metro Setup`: его установщик
регистрирует обработчик URI. Обычная редакция MSC Launcher не изменяется.

Сборка неподписанного пакета:

```powershell
.\gradlew.bat metroAppx
```

Сборка подписанного пакета для ручной установки (sideload):

```powershell
.\gradlew.bat metroAppxSideload
```

Команда создаёт временный сертификат подписи, экспортирует только публичный
`MSC-Launcher-Tiles.cer`, подписывает APPX и удаляет приватный ключ из хранилища.

Готовый sideload-набор с установочным скриптом:

```powershell
.\gradlew.bat metroAppxSideloadZip
```

Распакуйте ZIP, нажмите правой кнопкой на `Install.ps1` и запустите его через
PowerShell. Скрипт проверит издателя, добавит публичный сертификат только в
хранилище текущего пользователя и установит APPX.

Любой APPX необходимо подписать сертификатом, Publisher которого точно совпадает
с `CN=Meine Starten Corporation` из `AppxManifest.xml`. После установки доверенного
сертификата пакет можно установить командой `Add-AppxPackage`.
# Установка sideload-сборки

1. Распакуйте ZIP полностью в отдельную папку.
2. Запустите `Install.cmd` и подтвердите запрос контроля учётных записей Windows.
3. Скрипт проверит подпись, добавит приложенный сертификат в хранилище
   `LocalMachine\TrustedPeople` и установит APPX.

Не запускайте APPX напрямую до установки сертификата: Windows отклонит пакет с
ошибкой цепочки доверия `0x800B010A`.
